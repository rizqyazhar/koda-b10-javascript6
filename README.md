# Built-in Method dan Built-in Function

## BUilt-in Method

### String

`.repeat()`
Method ini digunakan untuk mengembailkan string baru sesuai dengan jumlah yang diinginkan

`.trim()`
Method ini digunakan untuk menghapus white space yang mungkin tidak sengaja ditambakan

`.substring()`
Method ini digunakan untuk mengambil string berdasarkan index awal hingga akhir index yang diinginkan, jika akhir index tidak diberikan maka akan otomatis mengambil sampai akhir string

`.padEnd()`
Method ini digunakan untuk memberikan string tambahan diakhir string dengan length tertentu. length dihitung dari index awal string.

`.startsWith()`
Method ini digunakan untuk mengecek apakah string dimulai dengan char atau string tertentu

### Array

`.toReversed()`
Method ini digunakan untuk mengubah urutan isi array namun mengembalikan array yang baru

`.includes()`
Method ini digunakan untuk mengecek apakah ada value yang ingin kita cari

`.slice()`
Method ini digunakan untuk mengambil item tertentu di dalam array berdasarkan index

`.shift()`
Method ini digunakan untuk membuang elemen pertama dari sebuah array dan mengembalikan elemen tersebut

`.join()`
Method ini digunakan untuk merubah array menjadi string dan bisa diberi string separator

### Object

`Object.groupBy()`
Method ini digunakan untuk mengumpulkan key dengan value yang diinginkan

`Object.keys()`
Method ini digunakan untuk mengambil setiap key yang ada di dalam object dan mengembalikannya kedalam array

`Object.keys()`
Method ini digunakan untuk mengambil setiap value yang ada di dalam object dan mengembalikannya kedalam array

`Object.hasOwn()`
Method ini digunakan untuk mengecek apakah didalam object ada property/key yang kita cari

`Object.create()`
Method ini digunakan untuk membuat object dengan menggunakan prototype objek yang sudah ada

### Boolean

`.valueOf()`
Method ini digunakan untuk mengecek apakah suatu value bernilai true / false

`.toString()`
Method ini digunakan untuk mengkonversi value boolean ke string

### Other

`Math.random()`
Method ini digunakan untuk mengembalikan nilai random dari >= 0 dan < 1

`Math.floor()`
Method ini digunakan untuk membulatkan nilai ke bawah

`.getFullYear()`
Method ini digunakan untuk mengambil tahun dari waktu local

### Built-in Function

`ParseInt()`
Method ini digunakan untuk mengkonversi suatu string argument ke integer

`ParseFloat()`
Method ini digunakan untuk mengkonversi suatu string argument ke decimal atau float

`isNaN()`
Method ini digunakan untuk mengecek apakah suatu value bernilai NaN.

`encodeURI()`
Method ini digunakan untuk merubah string ke dalam format url

`decodeURI()`
Method ini fungsinya adalah untuk me-decode format URI yang sebelumya dibuat menggunakan encodeURI()
